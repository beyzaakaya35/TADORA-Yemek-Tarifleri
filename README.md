**TADORA – YEMEK TARİFLERİ UYGULAMASI**

**Lezzetin Yeni Adresi**

TADORA, kullanıcıların farklı yemek tariflerini keşfedebileceği, kendi tariflerini ekleyebileceği ve kişisel tarif koleksiyonlarını yönetebileceği modern bir web uygulamasıdır.

**PROJE HAKKINDA**

TADORA, yemek tariflerine kolayca ulaşmayı ve kullanıcıların kendi tariflerini dijital ortamda düzenlemesini sağlayan kullanıcı dostu bir web uygulamasıdır.

**PROJE ÖZELLİKLERİ**

- Yemek tariflerini listeleme
- Tarifler arasında arama yapma
- Kategorilere göre filtreleme
- Tarifleri favorilere ekleme ve çıkarma
- Yeni tarif ekleme
- Mevcut tarifleri düzenleme
- Tarifleri silme
- Verileri LocalStorage ile saklama
- Mobil uyumlu tasarım
- Açık ve koyu tema desteği

**KULLANILAN TEKNOLOJİLER**

- HTML5 – Sayfa yapısı
- CSS3 – Tasarım ve görsel düzen
- JavaScript – Dinamik işlemler ve kullanıcı etkileşimi
- Bootstrap – Responsive tasarım
- LocalStorage – Verilerin tarayıcıda saklanması

**KURULUM VE ÇALIŞTIRMA**

1. Projeyi bilgisayarınıza indirin.
2. Proje klasörünü açın.
3. `index.html` dosyasını tarayıcıda çalıştırın.
4. Uygulamayı kullanmaya başlayın.

**PROJENİN AMACI**

Bu projenin amacı HTML, CSS ve JavaScript teknolojilerini kullanarak işlevsel, kullanıcı dostu ve mobil uyumlu bir yemek tarifleri web uygulaması geliştirmektir.

Proje kapsamında DOM işlemleri, olay yönetimi, fonksiyonlar ve LocalStorage kullanımı uygulanmıştır.
